# 1. Einleitung

## Ziel der Schulung

Diese Schulung vermittelt die Bedienung der Anwendung **Vier Gewinnt** innerhalb des Inflight-Entertainment-Systems (IFE).

Nach Abschluss der Schulung können die Teilnehmer:

* die Anwendung starten,
* einen Spielmodus auswählen,
* eine vollständige Spielrunde durchführen,
* Hilfefunktionen nutzen,
* das Spiel neu starten,
* Gewinnkombinationen anzeigen,
* zur Spielesammlung zurückkehren.

## Zielgruppe

Diese Schulung richtet sich an:

* Abnahme- und Testpersonal
* Integrationsverantwortliche
* Projektbeteiligte
* Demonstrations- und Schulungsteilnehmer

---

# 2. Überblick über die Anwendung

**4 Gewinnt** ist eine digitale Umsetzung des bekannten Spiels *Vier Gewinnt*.

Die Anwendung wurde speziell für den Einsatz innerhalb eines Inflight-Entertainment-Systems entwickelt.

## Eigenschaften

* Vollständiger Offline-Betrieb
* Bedienung per Touchscreen oder Maus
* Einzelspielermodus gegen einen Bot
* Mehrspielermodus für zwei Spieler
* Keine Speicherung personenbezogener Daten
* Keine Internetverbindung erforderlich

---

# 3. Spielziel

Ziel des Spiels ist es, vier eigene Spielsteine in einer zusammenhängenden Reihe anzuordnen.

Eine Gewinnreihe kann:

* horizontal
* vertikal
* diagonal

verlaufen.

Der Spieler gewinnt, sobald vier eigene Spielsteine verbunden sind.

---

# 4. Anwendung starten

## Vorgehensweise

1. Öffnen Sie die Spielesammlung des IFE-Systems.
2. Wählen Sie den Eintrag **"Vier Gewinnt"** aus.
3. Das Modusmenü wird angezeigt.

### Ergebnis

Die Anwendung wurde erfolgreich gestartet und ist spielbereit.

---

# 5. Öffnen der Einstellungen

Die Einstellungen können nur im Hauptmenü aufgerufen werden.

## Vorgehensweise

1. Schaltfläche **"Einstellungen"** wählen.
2. Neuer Bildschirm erscheint. Hier kann man nun über die obere Schalfläche die Sprache und über die untere die Airline CI einstellen.
3. Über den Button **"Hauptmenü"** kann man nun zum Hauptmenü zurückkehren.

---

# 6. Applikationshilfe Aufrufen

Die Applikationseinstellungen können nur im Hauptmenü aufgerufen werden. Für Spielhilfe bitte unter Punkt 9 Informieren.

## Vorgehensweise

1. Im Hauptmenü die Schalfläche **"Hilfe/Regeln"** wählen.
2. Neuer Bildschirm erscheint. Hier werden nun allgemeine Infos und eine kurze Bedienungsanleitung angezeigt.
3. Über den Button **"Hauptmenü"** kann man nun zum Hauptmenü zurückkehren.

---

# 7. Spielmodus auswählen

Nach dem Start stehen **drei** Spielmodi zur Verfügung.

## Spieler gegen Spieler

* Zwei Personen spielen abwechselnd auf demselben Bildschirm.
* Es wird kein Computergegner verwendet.

## Spieler gegen einfachen Bot

* Ein Spieler tritt gegen den einfachen Computer-Gegner an.
* Der Bot führt nach jedem Spielerzug automatisch seinen Zug aus.

## Spieler gegen schweren Bot

* Ein Spieler tritt gegen den schweren Computer-Gegner an.
* Der Bot führt nach jedem Spielerzug automatisch seinen Zug aus.

## Vorgehensweise

1. Gewünschten Modus auswählen.
2. Das Spiel wird automatisch gestartet.
3. Das Spielfeld erscheint.

---

# 8. Bedienung während des Spiels

## Spielstein setzen

Das Spielfeld besteht aus mehreren Spalten.

Ein Spielstein wird durch Auswahl einer Spalte gesetzt.

### Ablauf

1. Gewünschte Spalte auswählen.
2. Der Spielstein fällt automatisch auf die niedrigste freie Position.
3. Das Spielfeld wird aktualisiert.
4. Der nächste Spieler ist am Zug.

### Hinweis

Ist eine Spalte bereits vollständig gefüllt, kann dort kein weiterer Spielstein platziert werden.

---

# 9. Spielhilfe aufrufen

Die Spielhilfe kann jederzeit während einer laufenden Partie geöffnet werden.

## Vorgehensweise

1. Schaltfläche **„Hilfe / Regeln“** auswählen.
2. Die Spielregeln werden angezeigt.
3. Nach dem Lesen übern den Button **"Zurück"** zur Spielansicht zurückkehren.

### Hinweis

Das aktuelle Spiel wird dabei nicht unterbrochen oder zurückgesetzt.

---

# 10. Spiel neu starten

Ein laufendes Spiel kann jederzeit zurückgesetzt werden.

## Vorgehensweise

1. Schaltfläche **„Zurücksetzen“** auswählen.
2. Das Spielfeld wird geleert.
3. Eine neue Partie beginnt.

### Achtung

Der bisherige Spielstand geht dabei verloren.

---

# 11. Spielende

Eine Spielrunde endet in einem der folgenden Fälle.

## Sieg

Ein Spieler hat vier Spielsteine in einer Reihe verbunden.

### Ergebnis

Der Ergebnisbildschirm wird angezeigt.

## Unentschieden

Alle Felder des Spielfelds sind belegt und kein Spieler hat gewonnen.

### Ergebnis

Der Ergebnisbildschirm wird angezeigt.

---

# 12. Gewinnkombination anzeigen

Nach einem gewonnenen Spiel kann die Gewinnkombination dargestellt werden.

## Vorgehensweise

1. Ergebnisbildschirm öffnen.
2. Schaltfläche **„Gewinnkombination anzeigen“** auswählen.
3. Das Spielfeld wird erneut angezeigt.
4. Die vier gewinnbringenden Spielsteine werden hervorgehoben.

### Nutzen

Die Gewinnsituation kann dadurch nachvollzogen und überprüft werden.

---

# 13. Neue Runde starten

Nach Abschluss einer Partie kann sofort eine neue Runde gestartet werden.

## Vorgehensweise

1. Schaltfläche **„Neue Runde“** auswählen.
2. Das Spielfeld wird zurückgesetzt.
3. Eine neue Partie beginnt.

---

# 14. Rückkehr zur Spielesammlung

Die Anwendung kann jederzeit verlassen werden.

## Vorgehensweise

1. Schaltfläche **„Spielesammlung“** auswählen.
2. Das aktuelle Spiel wird beendet.
3. Die Spielesammlung wird angezeigt.

---

# 15. Häufige Situationen

## Spielstein kann nicht gesetzt werden

### Ursache

Die ausgewählte Spalte ist vollständig gefüllt.

### Lösung

Eine andere Spalte auswählen.

---

## Hilfe versehentlich geöffnet

### Lösung

Die Hilfe schließen.

Das Spiel wird an derselben Stelle fortgesetzt.

---

## Spielstand wurde zurückgesetzt

### Ursache

Die Schaltfläche **„Neustart“** wurde ausgewählt.

### Folge

Der vorherige Spielstand kann nicht wiederhergestellt werden.

---

# 16. Zusammenfassung

Mit **4-Connect** steht den Passagieren ein einfaches und intuitiv bedienbares Unterhaltungsspiel innerhalb des Inflight-Entertainment-Systems zur Verfügung.

## Wichtige Funktionen

* Spiel starten
* Spielmodus auswählen
* Spielzüge durchführen
* Hilfe und Regeln anzeigen
* Einstellungen ändern und anzeigen
* Spielfeld neu starten
* Gewinnkombination anzeigen
* Neue Runde beginnen
* Zur Spielesammlung zurückkehren

Die Anwendung arbeitet vollständig offline und wurde speziell für den zuverlässigen Einsatz auf Sitzmonitoren innerhalb des IFE-Systems entwickelt.
